# Datasheets and drawings

The documents Board A and Board B were designed from, copied from the raw downloads in `research/dl/` (which is not in git) by `tools/datasheets.py`. Do not edit this file by hand: add an entry to the list in that script and run `python3 -I tools/datasheets.py`.

Plain resistors and capacitors have no datasheet here. Origin "JLCPCB / LCSC" means the copy JLCPCB hosts for that LCSC part; "manufacturer" means the maker's own copy.

Files marked *local only* are not published: a supplier's private correspondence and its attachments, and documents whose public source is not recorded. They stay in `research/dl/` on the design computer.
